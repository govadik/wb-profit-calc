# WB Калькулятор чистой прибыли

Бесплатный калькулятор для продавцов Wildberries.  
Без API-ключа, без подписки, без передачи данных третьим лицам.

**[🚀 Открыть калькулятор](https://govadik.github.io/wb-profit-calc/)**

**[📘 Инструкция](https://govadik.github.io/wb-profit-calc/instruction.html)**

## Как пользоваться

1. Скачайте детализацию отчёта из ЛК WB (Финансы → Финансовые отчёты → Детализация → Скачать Excel)
2. Загрузите файл на сайт
3. Введите закупочную цену в жёлтые ячейки — прибыль посчитается автоматически

## Особенности

- Всё считается локально в браузере — данные не уходят на сервер
- Себестоимость сохраняется между отчётами
- История отчётов для отслеживания динамики
- Выгрузка / загрузка цен через Excel
