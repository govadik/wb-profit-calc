1. Где скачать отчёт WB

Калькулятор работает с детализацией еженедельного отчёта реализации из личного кабинета WB Partners.

На компьютере:

  1. Зайдите в ЛК WB Partners
  2. Перейдите в раздел Финансы → Финансовые отчёты
  3. Откройте вкладку «Еженедельные»
  4. Найдите нужную неделю и нажмите на номер отчёта
  5. В открывшемся окне нажмите «Скачать Excel» (детализация)

В мобильном приложении:

  1. На главном экране нажмите на виджет баланса
  2. Нажмите «Отчёты»
  3. Выберите период и нажмите «Скачать Excel»
Важно: скачивайте именно детализацию (файл с множеством строк по каждой операции), а не сводную таблицу. Сводная таблица — это одна строка с итогами, она не подойдёт.

2. Загрузка файла в калькулятор

Откройте файл wb-profit-calc-fixed.html в браузере (двойной клик).

Способ 1 — Перетаскивание:

  1. Найдите скачанный файл отчёта WB на компьютере
  2. Перетащите его в область «Перетащите файл сюда» в калькуляторе
  3. Калькулятор автоматически распознает колонки и заполнит таблицу

Способ 2 — Кнопка «Выбрать файл»:

  1. Нажмите на область загрузки или кнопку «Выбрать файл»
  2. Выберите файл .xlsx, .xls или .csv

Способ 3 — Вставка из Excel:

  1. Откройте скачанный отчёт в Excel
  2. Выделите все данные (Ctrl+A) и скопируйте (Ctrl+C)
  3. В калькуляторе нажмите в поле «Или вставьте данные из Excel»
  4. Нажмите Ctrl+V, затем кнопку «Обработать вставку»
Совет: если отчёт загрузился, но колонки не распознались, проверьте, что в первой строке есть заголовки «Артикул поставщика» и «Кол-во». Калькулятор понимает разные варианты названий колонок.

3. Ввод себестоимости

После загрузки отчёта таблица заполнится данными WB. Жёлтые ячейки в колонке Себестоимость — единственные, которые нужно заполнить вручную.

Как ввести цену:

  1. Найдите нужный артикул в таблице
  2. Кликните в жёлтую ячейку «Себестоимость»
  3. Введите закупочную цену за 1 штуку (без пробелов, точка или запятая для копеек)
  4. Нажмите Enter — прибыль и рентабельность пересчитаются автоматически

Автосохранение цен:

Введённая себестоимость сохраняется в браузере (LocalStorage). При следующей загрузке отчёта с теми же артикулами цены подставятся автоматически.

Обратите внимание: себестоимость указывается за одну штуку, а не за партию. Калькулятор сам умножит на количество из отчёта WB.

🔹 Строка ИТОГО

Внизу таблицы две итоговые строки:

  • ИТОГО — суммы по всем колонкам, включая общую прибыль и общую рентабельность
  • в т.ч. Затраты WB — детализация, из чего состоят расходы
Рентабельность в строке ИТОГО = Общая прибыль / Общая себестоимость × 100. Это правильная средневзвешенная рентабельность всего портфеля, а не среднее арифметическое по строкам.

5. Работа с закупочными ценами

Выгрузить цены → Excel:

  1. Нажмите кнопку «💰 Цены → Excel»
  2. Сохранится файл wb_prices_YYYY-MM-DD.xlsx с колонками: Название, Артикул, Код номенклатуры, Себестоимость
  3. Отредактируйте цены в Excel и сохраните

Загрузить цены ← Excel:

  1. Нажмите кнопку «📥 Цены ← Excel»
  2. Выберите отредактированный файл
  3. Калькулятор обновит цены в таблице и сохранит их в памяти
Удобно, если много артикулов: выгрузите пустой шаблон, заполните цены в Excel для всех товаров сразу, затем загрузите обратно — не нужно вводить по одной в браузере.

6. История отчётов

Калькулятор умеет вести историю загруженных отчётов, чтобы отслеживать динамику прибыли по неделям.

Как сохранить отчёт в историю:

  1. Загрузите отчёт WB
  2. В поле «Номер отчёта» (под кнопками) введите номер отчёта из WB
  3. В поле «Дата / период» укажите период отчёта
  4. Нажмите «💾 Сохранить в историю»

Что сохраняется:

  • Дата, номер отчёта, количество проданных штук
  • Выручка, расходы WB, себестоимость, чистая прибыль
  • Рентабельность за период

История хранится локально в браузере. Вы можете выгрузить её в CSV кнопкой «📤 Скачать историю» или очистить кнопкой «🗑 Очистить историю».

7. Сохранение калькулятора на диск

Калькулятор работает полностью в браузере без интернета. Вы можете сохранить его как обычный HTML-файл и пользоваться локально.

Кнопка «💾 Сохранить» в шапке:

  1. Нажмите кнопку «💾 Сохранить» в правом верхнем углу
  2. Браузер скачает файл wb-profit-calc.html
  3. Этот файл содержит калькулятор + все текущие данные из таблицы
Важно: при сохранении через кнопку «Сохранить» в шапку встраиваются только данные из таблицы, но не история отчётов и не сохранённые цены из LocalStorage (их браузер не включает в файл). Чтобы сохранить цены — используйте кнопку «💰 Цены → Excel».

8. Формулы расчёта

Основная формула прибыли (когда есть колонка «К перечислению»):

// Чистая прибыль по артикулу
Прибыль = К перечислению − Логистика − Хранение − Штрафы − Прочие удержания − (Себестоимость × Кол-во)

Альтернативная формула (если «К перечислению» не найдено):

// Когда отчёт без колонки «К перечислению»
Прибыль = Продажа − Комиссия − Логистика − Хранение − Штрафы − Эквайринг − Прочие удержания − (Себестоимость × Кол-во)

Что входит в «Прочие удержания»:

  • Операции при приёмке
  • Стоимость участия в программе лояльности
  • Сумма удержанных баллов лояльности
  • Корректировка вознаграждения WB
  • Разовое изменение срока перечисления
  • Минус компенсация скидки по программе лояльности

Рентабельность:

// Построчная и итоговая
Рентабельность = Прибыль / Себестоимость × 100

9. Частые вопросы

Почему «К перечислению» не совпадает с суммой на моём счёте?

«К перечислению» в калькуляторе = «Итого к оплате» в сводном отчёте WB. Реальная выплата на счёт может отличаться на сумму:

  • Комиссии за мгновенный вывод («Вывести сейчас»)
  • Банковской комиссии за входящий перевод
  • Задолженности или переплаты с прошлых периодов

Почему прибыль отрицательная?

Проверьте:

  • Введена ли себестоимость? Без неё прибыль = «К перечислению» минус расходы WB
  • Есть ли возвраты? Они уменьшают прибыль
  • Не завышена ли себестоимость?

Что делать, если колонки не распознались?

Калькулятор ищет заголовки по ключевым словам. Если файл не стандартный:

  • Убедитесь, что первая строка содержит русские заголовки
  • Попробуйте скопировать данные в Excel и вставить через поле «Вставить из Excel»
  • Проверьте, что файл не повреждён — откройте его в Excel

Данные уходят на сервер?

Нет. Все вычисления происходят в вашем браузере. Файл отчёта не загружается никуда, кроме вашего компьютера. Себестоимость хранится в LocalStorage браузера.

Работает ли без интернета?

Да, после первого открытия страницы калькулятор работает офлайн. Но для загрузки шрифтов и иконок лучше иметь подключение при первом запуске.

Как очистить всё и начать заново?

Нажмите «🗑 Полная очистка цен и истории» — это удалит все сохранённые цены, историю отчётов и текущую таблицу.
